USEFUL OPTIONS
Append --help to any subcommand to inspect its complete argument list.
For batch and reporting-audit, --report-page-size 25 creates a navigable paginated report.
--fail-on-refusal returns a failure code after saving reports containing refused cohorts.
Keep CSV, JSON, configuration and all report pages together when copying an analysis.
