# Complete teaching transcription

These four files express the ampicillin example from Brookshire et al., Table 1, DOI 10.3389/fvets.2024.1512582. The collection contains 62 S. pseudintermedius and five S. schleiferi. Ranks 34/61 and the complete ordered category panel are analyst-declared interpretations. The representative 2 for >1 is recorded-category bookkeeping; its measurement interval has no upper bound. A is the sample identifier and P the panel identifier. Changing these IDs requires matching changes in all files.
