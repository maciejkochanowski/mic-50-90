# Returning a published count

Run the command in [RETURNED_COUNTS.md](../../docs/RETURNED_COUNTS.md). The source counts and terms are recorded in SOURCE.json and the [original published-table example](../published_table/README.md). This example uses the existing Delma 2024 histogram compression demonstration. It adds the verified count 85/2902 above 0.5 mg/L to the original summaries and resolves the sample criterion <5%. No source-population or calibration claim is made.
