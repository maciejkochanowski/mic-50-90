# MIC-50-90 1.0.0 software distribution

The [software release](https://github.com/maciejkochanowski/mic-50-90/releases/tag/v1.0.0) provides a Windows application, Python wheel, source distribution and checksums. GitHub Actions builds and uploads the assets after its verification jobs succeed.

This repository contains the calculation engine, guided local application, tests, formal algebra, examples, licences and user documentation. Start with [the Windows guide](docs/GUI_GUIDE.md) or [the CLI distribution guide](docs/distribution-user-guide.md). [The command reference](docs/CLI_REFERENCE.md) lists all options.

Manuscripts, supplementary appendices and editorial figures are excluded from the repository, release assets and software deposits. They remain in the author's separate local article package. The original article package must never be selected as an upload source for this software release.

See [distribution policy](docs/DISTRIBUTION_POLICY.md), [Windows build](docs/BUILD_WINDOWS.md) and [software checks](docs/REPRODUCING_RESULTS.md). A software deposit on Zenodo must use the checked software assets or the corresponding source tag only.
