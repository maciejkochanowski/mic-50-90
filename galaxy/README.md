# Galaxy tools

MIC-50-90 has three Galaxy tools: *MIC-50-90 distribution bounds*, *MIC-50-90 laboratory report* and *MIC-50-90 check a received report*. They are published in the Galaxy Tool Shed by the Intergalactic Utilities Commission as [suite_mic_50_90](https://toolshed.g2.bx.psu.edu/view/iuc/suite_mic_50_90) and run on [usegalaxy.eu](https://usegalaxy.eu/?tool_id=mic_50_90_distribution), [usegalaxy.org](https://usegalaxy.org/?tool_id=mic_50_90_distribution) and [usegalaxy.org.au](https://usegalaxy.org.au/?tool_id=mic_50_90_distribution).

The wrappers in `tools/mic_50_90` are those of release 2.0.0, tested with `planemo test galaxy/tools/mic_50_90` for the article. The current wrappers are maintained in [galaxyproject/tools-iuc](https://github.com/galaxyproject/tools-iuc/tree/main/tools/mic_50_90).
