# Missing information and unavailable results

Missing values are not imputed. Censoring, absent metadata and a failed calculation have different meanings and are handled separately. The software analyses incomplete reports of a collection with a known denominator; it does not model missing individual assays or nonresponse. Users must establish the applicable measured-cohort denominator and record exclusions. A histogram's count sum defines n; calibration preparation can check it against the optional independently supplied original_n.

| Situation | Program response | Interpretation and next step |
|---|---|---|
| Missing cohort or panel join identifier; malformed CSV structure | File-level preflight stops before cohort analysis. | Correct the row identifiers or table structure and rerun. No cohort can be assigned to an unidentified row. |
| Identifiable cohort lacks n, either required quantile, a declared CSV rank convention, a valid panel or a target | That cohort receives a refusal and the detected missing fields; other valid cohorts continue. | Recover the metadata from the source. The program does not infer the tested panel from observed minimum and maximum values. |
| Left-, right- or interval-censored MIC category | The category and its open or closed endpoints remain in the analysis. | A censored category is observed information, not a missing value. Recorded and latent bounds can differ. A blank panel endpoint denotes an unbounded interval. |
| Blank optional minimum/maximum or both criterion fields absent | Analysis continues without that range constraint or criterion. | Absence is not zero. A criterion with only one of its two fields supplied is invalid. |
| Missing histogram category or blank count | The category-count workflow refuses the cohort, even if the omitted count might be zero. | Supply every declared category with an exact count, including explicit zeros. No isolate is added, removed or assigned to a category by imputation. |
| Malformed reporting variant, duplicate variant identifier or invalid discrete field | The affected specification is refused; an uninterpretable variant is not silently removed. Sample sizes, ranks, category indices and counts require exact integers. | Correct the metadata. A missing interpretation is not a proven empty set and cannot be discarded to narrow the union. |
| Impossible ordered summary or all valid reporting variants infeasible | No sample result is issued for that cohort. Only mathematically infeasible variants may be excluded, with reasons retained. | Check n, categories, extrema and ranks. A numerical solver failure is not evidence of mathematical infeasibility. |
| iid sampling is not declared, or compatible optional reference/calibration is absent | The CSV workflow retains valid sample bounds and marks the affected inferential layer unavailable. | The sample result remains interpretable for the observed collection. No reference is estimated from missing calibration data. |
| Any expected calibration cohort is incomplete, invalid or fails scoring | Calibration preparation retains the intended denominator and diagnostic scores, writes a null manifest and an empty target mapping, and returns status 2. | Correct source or extraction errors against the fixed roster. Omission of a difficult unit or replacement by a zero score is not allowed. |
| A planned held-out target is missing or unavailable | Calibration assessment keeps it in the intended denominator; its whole unit cannot count as an operational success. | Report availability and whole-unit containment separately. Duplicate, foreign or internally inconsistent observations stop the audit. |
| Optional fit has an invalid setting, fails numerically, or question search reaches its deadline | Completed independent results remain available; the affected result is unavailable or the search incomplete. No optimal question is claimed after an incomplete search. | Inspect the reason and completion status. The time limit is checked between work units and is not a hard interrupt of an individual solver call. |
| A returned count contradicts all sample variants, or conflicts only with calibration | Contradiction of every sample variant refuses the count analysis; calibration-only conflict preserves the updated sample bounds and marks calibration unavailable. | Verify that the exact count concerns the original cohort and denominator. A conflict is not a successful calibration outcome. |

These rules describe the CSV workflows. The lower-level JSON interface checks the fields used by the analysis before calculation; it does not automatically execute the separately supplied JSON Schema. Malformed optional calibration can stop that call. It retains a ceiling-rank default when a quantile has neither a rank nor a convention; this is a software convention, not evidence about the source publication. JSON callers should state ranks explicitly when interpreting published summaries. Malformed or duplicate JSON variants stop validation; only a valid variant proved infeasible may be excluded from analysis. CSV summary rows instead require an explicit convention for every variant.

Discrete inputs are checked exactly, with an upper limit of 9,007,199,254,740,991. Unknown reference labels, non-Boolean JSON flags and identifiers with surrounding spaces are rejected. Omitted valid reference categories have zero weight. File-writing commands reject collisions between inputs and outputs before writing, including existing aliases. See the Python interface for exact decimal probabilities and the limits of already rounded float inputs.

See [CSV workflows](CSV_WORKFLOWS.md) for fields and runnable commands, [Python interface](PYTHON_INTERFACE.md) for lower-level defaults, and [public functions](PUBLIC_FUNCTIONS.md) for outputs and checks.
