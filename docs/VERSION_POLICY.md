# Version and artifact identity

The library, command line, package metadata and output schema use version 2.0.0; saved results and reporting certificates of versions 1.0.0 to 1.0.3 can also be reopened. Version numbers follow semantic versioning: removing or changing a public command, option or function raises the major version. The release tag, source commit, Actions run and SHA-256 checksums identify the exact software assets.

Manuscripts and supplementary appendices are not part of the software repository or release. They do not enter Python package metadata or software deposits. PACKAGE_STATUS.json identifies the software scope; completed Actions records establish which checks actually ran.
