# Version and artifact identity

The library, command line, Windows application, package metadata and output schema use version 1.0.0. The release tag, source commit, Actions run and SHA-256 checksums identify the exact software assets.

Manuscripts and supplementary appendices are maintained outside the software repository and release. They do not enter Python package metadata or software deposits. PACKAGE_STATUS.json identifies the software scope; completed Actions records establish which checks actually ran.
