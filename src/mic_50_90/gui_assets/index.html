Why does the program ask how MIC50/MIC90 were calculated?

Different rules can select different observations in a small sample. Under the ceiling rule, sort the MIC values and use the first observation reaching 50% or 90% of n: for 20 isolates, observations 10 and 18. Select that rule only if the source states it, or if you deliberately accept it as an analysis assumption. It is not confirmed just because the paper reports MIC50/MIC90.

If the rule is unknown, do not guess. You can analyse available counts without these summaries, or assess stated alternative rules under the advanced options.

Add the observed MIC range (optional)

Use the smallest and largest MIC actually observed in this sample. These are different from the lowest and highest concentrations tested.

Compare alternative MIC50/MIC90 rules (advanced)

When the source does not establish a convention, add each defensible interpretation. Results include all compatible declared alternatives; these are assumptions, not verified source metadata.

Does the source give any other counts?

For example: “59 of 67 isolates had MIC ≤0.25 mg/L”. Add one row, enter 0.25, choose ≤, and enter 59. The program uses that information to narrow the possible distribution. Skip this section if no other counts are available.

Enter every category count, including zeros. Their sum must equal the original number of isolates.

What should the report show?

Ask for fewer, more precisely described MIC groups (optional)

With this request, the program finds the most detailed contiguous grouping supported at that width. For example, 10 allows a group percentage to span at most 10 percentage points, such as 20–30%. Leave blank to keep the supplied groups.

Extend the result to a population (optional)

Estimate beyond these isolates

Use this only when your sampling design supports conclusions about the population from which the isolates were drawn.

Leave unchecked if independence or the sampling population is unknown. Repeated isolates from the same animal/person, or clusters within a herd, farm or hospital, can violate independence. Selecting this box does not make a sample representative or correct for clustering. The sample description remains available.

For example, 10 permits 20–30%. The program shows how many adjacent groups meet this width at the selected confidence level. This is separate from numerical precision. Leave blank to skip grouping.

Find counts needed for this population precision

Each requested count has unit cost by default. A failed guarantee can mean some possible answers would still be too uncertain. It does not mean every sample would fail. Detailed costs and unavailable questions can be supplied in JSON.

Confidence concerns repeated sampling under the stated model. A time-limited refinement retains unresolved regions; it may return the baseline result.
