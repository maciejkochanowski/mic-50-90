# Embedded typography

CMU Serif and CMU Typewriter use the same source files as the appendices.
DejaVu Sans uses the Matplotlib source fonts. Latin Modern Math supplies
mathematical glyphs absent from the prose face. Web derivatives are named
MIC Web and stored in compressed WOFF containers. Copyright notices are
retained. Glyph outlines, character mappings, metrics and layout tables
are verified unchanged by prepare_fonts.py. No subsetting is applied.
FONT_MANIFEST.json binds originals and web assets by SHA-256. The attached
OFL, GUST and DejaVu notices apply to the corresponding font files.
